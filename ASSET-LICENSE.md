# Pixel Break Buddy visual assets

## Origin and inventory

The project creator confirms that the Happy, Annoyed, and Angry PNGs were generated
using ChatGPT. The walking sprite sheet was also generated using ChatGPT, based on
the creator's original mascot design. The creator intends to include these images
in Pixel Break Buddy and distribute them with the application and its source repository.
This records the creator's account of provenance; it is not independent clearance
of every possible third-party right.

| Files | Origin |
|---|---|
| assets/mascot/state-happy.png | ChatGPT-generated Happy state |
| assets/mascot/state-annoyed.png | ChatGPT-generated Annoyed state |
| assets/mascot/state-angry.png | ChatGPT-generated Angry state |
| assets/mascot/walking.png | ChatGPT-generated walking sheet based on the original design |
| assets/mascot/walking-aligned.png | Locally aligned derivative of the walking sheet |
| build/icon.icns | Locally generated derivative of the Happy PNG |
| assets/tray/buddyTemplate.png, buddyTemplate@2x.png | Locally code-drawn monochrome mascot-inspired menu-bar icons |
| Future screenshots/demo media in docs/ | Captures of the app; any desktop or third-party content must be reviewed before inclusion |

The duplicate assets:mascot folder is local working material, excluded from Git.
No stock artwork provider, downloaded sound sample, or bundled font file has been
identified in the project.
