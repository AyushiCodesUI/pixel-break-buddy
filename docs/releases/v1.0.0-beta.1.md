# Pixel Break Buddy v1.0.0-beta.1 — friends beta

Release tag to use later: `v1.0.0-beta.1`  
Release type: **Pre-release**  
Platform: **macOS 13 or later · Apple Silicon (arm64)**

This is the first downloadable friends-beta candidate for Pixel Break Buddy: a
pixel-art desktop companion that reminds you to take work breaks. These notes are
prepared locally; no Git tag or GitHub Release has been created by the build process.

## Included

- Work, break, and snooze timers with saved local settings.
- Walking entrance, Happy/Annoyed/Angry expressions, reminder bubbles and controls.
- Original retro emotion sounds, volume/mute, and sound previews.
- Mascot customization and a native menu-bar icon with timer controls.
- Show Test Reminder Now / End Test Reminder for immediate previews.
- Packaged Launch at Login and reduced-motion support.

This beta changes versioning and packaging; existing application behavior and
mascot artwork are preserved. Electron remains 45.3.4. The bundle identifier remains
`com.pixelbreakbuddy.app`; updates use the same local preference folder.

## Important installation warning

**This limited beta is ad-hoc signed. It is not Developer ID signed or notarized by
Apple.** macOS may block an internet-downloaded copy, and a local signing verification
is not Apple approval or a malware certification. Only install a copy received from
the trusted project maintainer and verify its checksum.

If macOS blocks it, consult [Apple's specific-app opening guidance](https://support.apple.com/en-us/102445),
including System Settings → Privacy & Security → Open Anyway when available. Do not
disable Gatekeeper or remove quarantine protections globally. No bypass commands
are required or provided here. Managed Macs may prohibit unnotarized apps.

## Install or update

1. Quit any running Pixel Break Buddy copy from its menu-bar menu.
2. Open the DMG. Drag **Pixel Break Buddy.app** onto the **Applications** shortcut.
   Choose Replace when updating the existing copy; preserve your preference folder.
3. Eject the installer, then open Pixel Break Buddy from Applications in Finder.
4. The mascot is hidden during work; use the Buddy menu-bar icon to open Settings
   or choose **Show Test Reminder Now**. End the preview with **End Test Reminder**.
5. Enable/check Launch at Login only after the app is in its permanent location.
   Check System Settings → General → Login Items if macOS requests approval.

No Node.js, npm, Terminal, Cursor, or Codex is needed to run the installed app.
Do not run the app from the mounted DMG as your permanent installation.

## Compatibility and known limitations

- Apple Silicon only; no Intel installer is included. Minimum macOS version is 13.
  Physical testing on every supported macOS version/hardware combination has not
  been performed.
- No automatic updates; quit and manually replace the app for later betas.
- This is a break-reminder aid, not a medical product. Timing is not a health guarantee.
- Preferences stay at `~/Library/Application Support/pixel-break-buddy/`. Current
  sessions start fresh on relaunch; saved settings persist.
- The last audit reports **11 build-tool dependency entries (6 high, 5 moderate)**,
  rooted in minimatch and picomatch denial-of-service advisories. Those modules are
  excluded from the app. Developer/CI build risks remain; see PUBLIC-RELEASE-AUDIT.md.
- A downloaded/quarantined installer still needs testing on another Mac; local
  mounting and verification do not guarantee another system's Gatekeeper behavior.
- Mascot visuals have separate project-specific permissions, not the MIT source
  license. The app retains source/asset notices and Electron/Chromium notices.
