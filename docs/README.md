# Portfolio media and project documentation

A cropped GIF and the original MP4 recording are available in demo/ and linked from
the project README. Separate screenshots have not been added. See demo/README.md
for specifications, editing notes, and the full recording’s privacy-review items.
Capture the actual app; do not present generated mockups as working product evidence.

Suggested media:

- screenshots/reminder-happy.png: stationary mascot and reminder controls.
- screenshots/emotion-states.png: the three real expressions with timing captions.
- screenshots/settings.png and screenshots/customization.png: the actual windows.
- screenshots/menu-bar.png: status, controls, and immediate preview action.
- demo/: a short walking → Happy → Annoyed → Angry → break/snooze recording.

Use a clean desktop and hide personal filenames, account names, messages, browser
profiles, notifications, and unrelated applications. Crop or redact anything private.
Keep image files compact; host a compressed demo through GitHub's media uploader or
another chosen host later instead of committing a large raw video. Do not invent
screenshots, usability research, metrics, endorsements, or download links.

Describe what each capture shows, add alt text when embedding it in README.md, and
include captions/transcript for a demo. App visuals are separately licensed under
ASSET-LICENSE.md; review any third-party desktop content before publication.
