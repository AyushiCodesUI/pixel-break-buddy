## Preview preparation

The GIF uses a fixed crop at source pixel x=1412, y=530, width=440, height=450, with
no scaling or blur filters. GIF palette encoding is lossy; the original recording's
resolution and art edges are preserved as closely as the format permits. Requested
sampling was 8 fps; GIF hundredth-second timing rounds most frames to 0.13 seconds.
It loops indefinitely and has no audio.

Excerpts use approximately 4–8 seconds (Happy), 12–16 seconds (Annoyed), and
17.5–18.25 seconds (Angry) of the source. The final Angry frame is held for about
3.38 seconds so the message can be read. This is an edited preview, not a depiction
of the production reminder's real two-/three-minute thresholds.

The original MP4 includes one audio track and has not been re-encoded or stripped
of metadata. A checksum check confirmed its bytes were unchanged during preparation.

## Text description

The pixel-art girl appears near the bottom-right of the desktop. Happy reads
“Time for a little break!” with Take a Break and Remind Me Later controls. Annoyed
reads “Still working?” Angry reads “Break time. Seriously!” The original full video
also shows desktop/application switching and a break countdown.
